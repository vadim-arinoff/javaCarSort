#Java114 Multi Car Sort

Мы делаем одну консольную программу для автомобилей. Пользователь выбирает, сколько автомобилей создать и откуда их взять: ввести вручную, прочитать из файла или сгенерировать. Затем выбирает сортировку по мощности, модели или году. Программа показывает результат и продолжает работать, пока пользователь сам не выберет выход.  

Работу делим по частям:  

Ершов Вадим          — собирает проект, делает меню и соединяет части программы.
Плотников Кирилл     — класс Автомобиль, Builder и проверка его полей.
Белозерцев Владислав — собственная коллекция и случайное заполнение.
Усманов Булат        — ручной ввод, чтение и запись файла.
Сероноженко Григорий — два алгоритма сортировки по трём полям.
Ерин Леонид          — особая сортировка чётных мощностей и многопоточный подсчёт.

Каждый проверяет свою часть ручными тестами и работает в своей Git-ветке. Потом соединяем все части в одну программу через PR.
