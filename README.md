# Java114 Multi Car Sort

Мы делаем одну консольную программу для автомобилей. Пользователь выбирает, сколько автомобилей создать и откуда их взять: ввести вручную, прочитать из файла или сгенерировать. Затем выбирает сортировку по мощности, модели или году. Программа показывает результат и продолжает работать, пока пользователь сам не выберет выход.

## Возможности

- Ручной ввод, случайная генерация и загрузка автомобилей из файла.  
- Выбор количества автомобилей при заполнении.  
- Сортировка пузырьком или выбором по мощности, модели и году производства.  
- Особый режим: автомобили с чётной мощностью сортируются по возрастанию мощности, а автомобили с нечётной мощностью остаются на исходных позициях.  
- Подсчёт вхождений автомобиля с использованием нескольких потоков.  
- Добавление текущей коллекции в файл без удаления прежних записей.  
- Проверка входных данных и JUnit-тесты.  

Алгоритмы сортировки реализованы вручную. Для хранения автомобилей используется собственная изменяемая коллекция.  

## Запуск

Run в VsCode на файле src\main\java\ru\team114\carsort\Main.java

## Данные автомобиля

Один автомобиль содержит три поля:  
 `power` — Положительная целая мощность  
 `modelName` — Непустое название модели  
 `productionYear` — Год от 1886 до текущего  

Автомобили создаются через `Car.Builder`, который проверяет значения полей.  

### Входной JSON

Обычный файл `.json` содержит массив автомобилей:

```json
[
  {
    "power": 120,
    "modelName": "Toyota Corolla",
    "productionYear": 2020
  },
  {
    "power": 95,
    "modelName": "Kia Rio",
    "productionYear": 2022
  }
]
```
### Файл результата

По умолчанию результат записывается в `results.json`.

```json
[{"power":349,"modelName":"Dodge Challenger 1970","productionYear":1971},
{"power":110,"modelName":"Lada Vesta","productionYear":2022},
{"power":101,"modelName":"Ford Focus","productionYear":2018}]
```

Повторная запись добавляет строки в конец файла.  

## Пакеты проекта

`model` — Автомобиль, Builder и проверка его полей  
`collection` — Собственная коллекция и операции с её элементами  
`input` — Ручной ввод, генерация и чтение файлов  
`sorting` — Стратегии сортировки и правила сравнения полей  
`output` — Запись автомобилей в файл  
`multithreading` — Параллельный подсчёт вхождений автомобиля  

`Main` связывает эти части через консольное меню. Сортировка изменяет текущую коллекцию, поэтому результат можно показать на экране или записать в файл.  

## Проверка

JUnit-тесты расположены в src/test/java. Они проверяют модель, коллекцию, ввод и вывод, оба алгоритма сортировки, особый режим и подсчёт.
